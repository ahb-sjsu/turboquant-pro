# REVAL-2026-08-08 — re-validation matrix for the long-generation negative

Final comparison matrix of the 2026-08-08 re-validation of
[`results_longgen.json`](results_longgen.json) (the recorded long-generation
degradation of 4-bit asym-NF4 KV quantization). Each cell re-runs the repo's own
harness (`tq_paper_lb_shard.py`, unmodified, on the committed `NF4A` env line)
and scores with **LongBench's own `metrics.py`** — the same module
`tq_enh_agg.py` imports. **n = 40** documents per cell (`NUM_SHARDS=5
SHARD_ID=0`, i.e. indices 0, 5, …, 195 — an unbiased subsample; both arms see
identical documents). Raw generations, logs and per-row scores live under
**`/archive/c12/reval/`** on the Atlas workstation.

Bottom line: the recorded `nf4a` curve does not reproduce (gov_report Qwen 512:
measured gap **−0.31** vs recorded **13.70**); the **symmetric** `nf4` codebook
produces a real and larger collapse on the same cell (gap **26.64**). Analysis
and positive controls: [`../RESULTS_longgen_revalidation.md`](../RESULTS_longgen_revalidation.md).
Errata trail: `CHANGELOG.md` (Errata, 2026-08-15).
